# ZombieCash heroine reference

`heroine-canonical-reference.webp` is the canonical visual identity reference for the ZombieCash heroine.

The bot uses the same image-to-image reference URL for both HUMAN and UNDEAD generations so the character keeps one recognizable face and facial proportions across both forms.

The scene's FORM instruction controls the transformation:
- HUMAN: dark hair, natural eyes, tactical camouflage, confident action-hero posture.
- TRANSITION: gradual infection only as specified by the scene.
- UNDEAD: silver-white hair, vivid magenta eyes with amber-red cores, visible signature scars, biohazard goggles and pendant, bold black post-apocalyptic wardrobe.

The reference is a visual identity anchor, not a command to copy the source pose, background, text, or clothing. The generated scene should remain new and context-specific.
