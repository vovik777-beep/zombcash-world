# ZombieCash — The Undead Internet

A free, static first-version concept site for the ZombieCash ecosystem.

## What's in this prototype
- Neon cyberpunk / survivor-terminal / comic-apocalypse visual blend
- Responsive layout for desktop and mobile
- Radar, Zombie Lab and community entry points
- Simulated outbreak indicator, clearly marked as demo and not live data
- Tiny browser reaction-time survival game
- Copyable ZombieCash token contract
- Links to existing Telegram and X community destinations

## Run locally
Open `index.html` in a modern browser. No build step or API key is needed.

## Deploy with GitHub Pages
1. In **Settings → Pages**, choose **Deploy from a branch**.
2. Select branch `main` and folder `/ (root)`.
3. Save and wait for GitHub Pages to publish the site.

This is a static prototype. The Radar cards currently link to existing bots; live market data, server-side AI, user accounts, shared leaderboards and persistent game progress are future integration steps. The outbreak indicator is decorative demo data, not a live market signal. Never put private API keys in these public files.
